## Security Posture

- IMDSv2 enforced on EC2 (HTTP tokens required)
- EBS root volume encrypted at rest
- SSH password auth disabled (key-only)
- UFW firewall — minimal open ports (22, 80, 443)
- OS hardening via Puppet (sysctl, fail2ban, SSH config)
- Security Group — port 8080 internal only (Nginx proxies)
- Docker runs as non-root user (idpapp)
- OWASP Dependency Check gates build on CVSS ≥ 9
- SpotBugs High threshold gates build
